# Aknal Crystal Rock Combined

`Aknal_Crystal_Rock_Combined_Final.fbx` contains one joined mesh made from the supplied rock and crystal FBX files. The main crystal is embedded into the rock, two smaller crystal companions fill the base, and the lowest crystal facets use a transition rock material to hide the seam.

The accompanying PNG maps are copied beside the model so Unity can resolve the material textures on import. `Aknal_Crystal_Rock_Combined.blend` keeps the editable source scene, and `Preview_Aknal_Crystal_Rock.png` shows the result.
